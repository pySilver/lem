# The guides do not say that a task can wait for another task

Since `owner-task-order-stays` (2026-11-21), a request whose words put it after another task
("After gift-note-in-export: ...", "when the gift note task lands") is queued behind that task, and
the owner's "start SLUG now" starts it before that (`skills/lem/stages/new.md`, steps 1, 5 and 7;
`skills/lem/stages/start.md`, "`/lem build`"). `docs/flow.md` has one sentence on the wait.

`README.md`, `docs/when-lem-needs-you.md` and `site/index.html` say neither that a request can wait
for another task nor that "start SLUG now" starts it. No sentence of theirs is false; a reader who
types an ask that begins "After ..." learns from the first line of the task's session only. A
sentence in each, in STE, with the site written from the README as its layout says, closes the gap.
