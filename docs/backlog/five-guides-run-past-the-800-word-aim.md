# Five guides run past the 800-word aim

`docs/rulings/rulings.md` gives each guide of `docs/` an aim of under 800 words, "or a bit more
when needed". On 2026-11-26, `wc -w docs/*.md` in `rb/guides` counts the Markdown source,
including code blocks.

- `flow.md` has 913 words.
- `install.md` has 872 words.
- `merge.md` has 888 words.
- `board.md` has 847 words.
- `when-lem-needs-you.md` has 810 words.

The owner asked on 2026-11-24 to cut the guides at release 1.0.0. He said, "The 800 is no hard rule".
