# Findings

1. **A scratch repository does not isolate the owner’s board.** In `src/lem/serve_hook.py:50–54`, `main` uses `home = lem_state.config()` and starts `"serve", "--ensure"`. In `serve.py:5321–5341`, `ensure_held` can call `stop_server(settings["port"], found)`. A scratch task with the owner’s configuration can therefore replace his server. An older installed command can also win on the task’s PATH even with `claude --plugin-dir` (AGENTS.md, “Checks,” records that observation). Before the stage 2 baseline, give the trial its own Claude configuration, Lem home and port, as `tests/lib.sh:13–34` does. Keep automatic start enabled for this journey. Record the command actually resolved, its version and root, and the server’s reported root and PID. Repeat under the formula in stage 3. **Read** the paths. The outcome on the owner’s machine was not tested.

2. **The Homebrew install changes the meaning of “root” for running sessions, data files and server upgrades.** `src/lem/paths.py` sets `ROOT = PACKAGE.parents[1]` and `SKILLS = ROOT / "skills"`. In a normal wheel layout that ancestor is an interpreter directory. `session.py:230,723–732,1280` passes that root to `plugin_dir`, which returns it for a folder outside Claude’s plugin tree. A child Claude session can receive an interpreter directory as its plugin. Separately, `serve.code_stamp` scans `folder.glob("*.py")` under checkout-relative paths and defaults to zero. `serve.outdated` compares timestamps before versions. An installed app with a zero stamp can keep an older server with a positive stamp. The tagged v0.3.1 server uses the same comparison. Give the executable, active plugin, packaged data and running server distinct identities. Test a fresh install and an upgrade over a live old server, including a second project with a different plugin version. In `release.installed`, `found = own or user` gives a project install priority. An old open session, a fresh mismatched session and the detached server can therefore have different answers. Specify where each obtains the active plugin version. Keep the owner’s mismatch stop and the old command grammar. The grammar alone cannot establish which plugin sent the command. **Read** the current and tagged paths. The proposed install layout is untested.

3. **An event can retain every old key and still disappear from an old landing.** At tag `v0.3.1`, `skills/lem/scripts/land.py:2756`, and on main, `src/lem/land.py:5164`, `events_of` filters text before it parses JSON: `if f'"task": {json.dumps(task.slug)}' not in line:`. I ran `probe/.venv/bin/python -I -B probe/record_edges.py` on the isolated function from the tag. For the same event, `json.dumps` printed `matched 1` and Pydantic’s `model_dump_json` printed `matched 0`. The missing space did it. Keep the current JSONL writer for the release. Test old bytes with the new reader **and** new bytes with the tagged reader. Round-trip unrecognized keys through partial updates. `land.Task.keep` currently writes `{**self.kept(), **values}`. A model that drops an unknown field can erase another step’s work. Use fixtures for an unfinished polish, a carried review and a pruned task, alongside a complete landing. **Ran** the reader comparison. **Read** the update path.

4. **The hook import test passes when both sides acquire the same slow dependency.** In `tests/unit/test_python.py:140–160`, `HookStart` starts the launcher and then the same hook directly. Its assertion is `self.assertEqual(started - alone, set())`. In `corrections.machine_says_yes`, a prompt already reaches `machine_table("corrections")` to find out whether collection is off. A model imported from `state.py` taxes both sides. Before stage 3, record the modules and elapsed time on the disabled prompt, session start, compaction and a small command. Check the installed entry against those paths again after each dependency moves. Keep a separate comparison for launcher overhead. **Read** the test. **Measured** library costs below.

5. **A change to the command parser can silently turn internal calls back into child processes.** `src/lem/sibling.py`, `in_form`, searches the source for `r"^def main\(argv\b"`. `run` starts a process when that match disappears. `land.project_now` also switches to the stand-in path and calls the project commands separately. On the other path, `sibling.run` uses `contextlib.redirect_stdout(out)`. `serve.lem_run` therefore holds `SCRIPT_LOCK` while it runs a command. Extract the functions used by the server and landing before converting their parsers. Return values and typed refusals there. Keep process boundaries for `criteria red`, `project serial` and `serve.merge_apart`, with their cancellation and lock behavior. Keep the release scope of `release.one_command` around nested calls. **Read** these branches. The cost of the proposed command tree is unmeasured.

## Package boundaries

- **Landing.** In `land.py`, group `line_join/line_live/gate_look/wait_for_load` as admission to checks. Group `checks_run/checks_body/checks_stop` as their execution. Put `rebased_files/pairs/through_rebase` with rebase evidence. Put `cmd_merge_review/merge_locked/forge_done` with the forge operation. `pr_text:7864–7928` mixes record reads, criteria, events and formatting. Collect those inputs once before extracting the formatter. `Task.keep` and the enclosing step lock remain shared across steps.
- **Project.** In `project.py`, group `committed_settings/load/decide` under settings, `claim_ticket/link_mark/give_back` under ticket ownership, and `cmd_state/append_event` under task transitions. Keep `record_problem/cmd_proposals_verdict/cmd_proposals_drop` together. Put `summary_of/summarized_log/rewrite_log` with retention. A generic writer cannot substitute for `link_mark`’s `os.link(fresh, mark)`: the first claim must survive a competing claim.
- **Task state shared with the board.** Extract `derive/fold/fold_summary/settle` from `board_model.py` before changing the pages. `project.summary_of` calls `bm.derive(rest, [], now)` to write permanent history. `project.cmd_waiting`, `inbox.Watcher` and `push.Watcher` consume `waits_of`. Keep one rule there. Within `time_of`, extract the event pairing in `pair`, the landing intervals in `landing`, and the stage bands in `stage_of/band`. Each currently closes over the same event positions or result lists. Keep overlapping intervals counted once for `time_shares`. In `time_of`, events belong to state blocks by log position. Sorting them by timestamp changes the answer. Leave file offsets, inode checks and cached mutable models with `Reader.current`.
- **Board service.** In `serve.py`, separate `Door/door_refusal/action_refusal` and HTTP dispatch from `act_answer/row_refusal` and task writes. Group `forge_once/duties/run_duties/prune_once` as the server’s work across tasks. Group `ask/start_server/outdated/ensure_held` as process control. `Workspace.model` calls `reader.current(board)`, then overlays live sessions and forge state. Preserve one shared workspace per repository. The kernel can own process and file primitives. The server owns the decision to wake a task or run a duty. The session module owns agterm’s execution context.

## Current defects

1. **Joining a peer can delete valid neighbors.** `peers.Peers.table:635–637` returns `{}` on a `StateError`. `join:750` then writes `{**table, name: port}`. I ran the real settings writer with a scratch file and a stubbed network reply. With valid `beta = 4537` beside `broken = "bad"`, joining gamma printed `remaining peers {'gamma': 4537}`. Refuse an invalid table before an edit. Apply the individual change under `state.machine_lock`, including the read. **Ran**, [record probe](probe/record_edges.py).
2. **A blank resume link can stop a task indefinitely.** In `project.resumed_slug:3865–3868`, the loop continues while the file exists, then assigns `.strip() or first`. A blank `resumed-from.txt` leaves both variables and files unchanged. A cycle also repeats. Refuse the empty link or repeated slug with its path. **Read**, including the callers in `cmd_resume` and `open_resumed`.
3. **The board can direct a repair to the wrong event line.** `board_model.Reader.read_log:6703` initializes `number = len(self.events) + len(self.log_bad)` and skips blank lines. After a blank line and a valid event, I appended invalid JSON on physical line 3. The next read printed `line 2 is no event with a time`. Start from `self.log_lines`, which already counts physical lines. **Ran**, [record probe](probe/record_edges.py).

I did not run a Lem command, hook, board server, test suite, Homebrew upgrade or live task. The brief reserves the owner’s running board. The import and record probes establish the cases above. Installed behavior, actual command latency, browser behavior and delivery to a subscribed device still require the staged trials.
