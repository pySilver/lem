# The cast of Lem

The people a persona panel asks before a hard question reaches the owner. The owner chose these
three at the onboarding on 2026-11-16; the files are drafts written from the repository and are
for him to correct.

| Persona | File |
|---|---|
| The developer at the three touches: runs Lem in his own projects, answers its questions, merges its pull requests | `developer.md` |
| A teammate in a repository that adopted Lem: did not install it, meets its pull requests and its settings in git. **A thin guess** | `teammate.md` |
| A developer who tries Lem for the first time: reads the README, runs the setup and `/lem init`, decides in an hour. **A thin guess**: correct it first | `newcomer.md` |
