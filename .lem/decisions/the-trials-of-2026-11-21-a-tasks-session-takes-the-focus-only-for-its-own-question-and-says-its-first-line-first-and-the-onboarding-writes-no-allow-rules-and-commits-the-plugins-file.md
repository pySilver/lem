# The trials of 2026-11-21: a task's session takes the focus only for its own question and says its first line first, and the onboarding writes no allow rules and commits the plugin's file

Real tasks in lem-trial and lem-scratch, on Lem 0.1.3, showed four things. A fast-track session
opened with the focus could not close after its merge: the owner never left a session he never
chose, and `lem session close --when-unselected` waited. So no caller gives the focus (`--focus` is
gone), and a task's session takes it once (`take-focus`) at its first question for him. Two of
three new sessions started an agent before their first line, so he never saw the branch or the
track: `prompts/session.md` makes that line their first words. Auto mode refused the onboarding's
write of `.claude/settings.json`, and with no allow rules no builder was blocked: the rules are an
offer for a developer outside auto mode. The plugin's entry in that file stayed untracked, so a
clone had no Lem: the onboarding commits it.
