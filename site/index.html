How a task goes Install GitHub

Type a request in plain words, and get a pull request whose first line says green or not green.

Agents plan, build, test and review the change in your repository. Lem is a plugin for Claude Code that works closely with agterm.

claude plugin marketplace add pySilver/lem --scope project
claude plugin install lem@lem --scope project

Lem needs agterm. Run the two lines in your repository, then type /lem init.

01 · How a task goes

Two tracks to one pull request

Lem reads each request, and tells you its type and its track in one line.

Fast track

  1. Your request
  2. One builder makes the change
  3. Checks and one read
  4. Pull request you merge it

Standard track

  1. Your request
  2. Interview you answer
  3. Acceptance criteria you say yes
  4. Plan and build a builder for each part
  5. Checks and a review
  6. Pull request you merge it

You act here.

The fast track is for one plain change with no open question: a typo, a rename, the fix of one rule. One builder makes it, and nothing waits for you.

The standard track is for every other request: an interview, acceptance criteria for your yes, a plan, and a larger review.

On both tracks, the checks run your tests, and an agent that did not build the change reviews it. The first line of the pull request says green or not green. Green means you can merge without a read.

02 · When Lem needs you

Three points, and Lem does the rest

  1. The interview On the standard track, the interview opens in a companion session under Lem's session. It asks one question at a time, each with its guess. You answer, or say yes to the guess. Lem's own session takes your next request at once.
  2. Your yes to the acceptance criteria Each criterion is a rule in plain words with one real example. You give your yes in the same companion, and it closes. Nothing builds before your yes.
  3. The merge You merge the pull request. On the fast track, this is the only point.

Lem takes every other decision itself. The pull request lists each one with its reason.

Type /lem im-away, and the tasks go on without you. Lem merges nothing for you while you are away. Type /lem im-back when you are back.

03 · The board

Every task in one place

The board puts each task in a lane by who acts next. Type /lem to open it, with the list of what waits for you.

04 · Install

Start in your repository

At the root of your repository:

claude plugin marketplace add pySilver/lem --scope project
claude plugin install lem@lem --scope project

Then start Claude Code in agterm there, and type /lem init. Answer three questions, read Lem's page, and type "land". Then type your first request.

Install lists the tools that Lem needs, and /lem init checks each one. Codex is optional and highly recommended: with it, a second model family reviews the larger changes.

Lem keeps its settings in the .lem/ folder of your repository, in git. To remove Lem, follow the steps in Remove.
